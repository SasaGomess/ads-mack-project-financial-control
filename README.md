# Poupa Mais 💸🪙

O **Poupa Mais** é uma aplicação para ajudar no controle das finanças pessoais de
forma simples e acessível. O projeto foi pensado principalmente para incentivar
pessoas de baixa renda e com pouca educação financeira a acompanharem melhor seu
dinheiro, organizarem suas despesas e tomarem decisões financeiras mais
conscientes.

> Projeto desenvolvido para a disciplina de **Web Mobile** do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Mackenzie**.

---

## 🎯 Objetivo

Oferecer uma ferramenta prática e inclusiva para registrar receitas e despesas, categorizar gastos, vislumbrar a saúde financeira do usuário e incentivar a educação financeira diária através de uma interface amigável.

---

## Tecnologias

- **[Node.js](https://nodejs.org/)** — Ambiente de execução JavaScript/TypeScript.
- **[TypeScript](https://www.typescriptlang.org/)** — Superset JavaScript para tipagem estática e maior segurança.
- **[NestJS](https://nestjs.com/)** — Framework modular e escalável para desenvolvimento Node.js server-side.
- **[MongoDB](https://www.mongodb.com/)** — Banco de dados NoSQL focado em flexibilidade de documentos.
- **[Mongoose](https://mongoosejs.com/)** — ODM (Object Data Modeling) para modelagem e validação dos dados no MongoDB.
