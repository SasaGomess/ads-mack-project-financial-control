# Poupa Mais 💸🪙

O **Poupa Mais** é uma aplicação para ajudar no controle das finanças pessoais de
forma simples e acessível. O projeto foi pensado principalmente para incentivar
pessoas de baixa renda e com pouca educação financeira a acompanharem melhor seu
dinheiro, organizarem suas despesas e tomarem decisões financeiras mais
conscientes.

Este projeto foi desenvolvido para a disciplina **Web Mobile**, do curso de
**Análise e Desenvolvimento de Sistemas (ADS)** da **Universidade Presbiteriana
Mackenzie**.

## Tecnologias

- Node.js
- TypeScript
- NestJS
- MongoDB
- Mongoose

## Objetivo

Oferecer uma ferramenta amigável para registrar receitas e despesas, acompanhar
os gastos e estimular hábitos financeiros mais saudáveis.
